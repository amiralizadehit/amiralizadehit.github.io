For:  Hobby Project

Two hobby apps exploring LLM integration patterns. Review Summarizer displays customer reviews (star rating, author, date, content) for a product and, on click, generates an AI summary of all the reviews via a Hugging Face LLM, caching the result in the database for a week so repeat visits don't regenerate it. WonderWorld Chatbot is a theme-park customer-service chat widget that sends each message to OpenAI along with a system prompt describing the park (hours, attractions, dining, etc.), replying in character and threading each reply to the previous one to maintain conversation memory.
